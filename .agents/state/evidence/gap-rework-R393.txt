1. **新写的「派生前锚点/形态体检」探针首跑红：白名单与判据范围未按**实际源产物形态**枚举**（判据侧缺陷；失败点在**写出任何交付产物之前**，运行当场终止、**未产出错误产物**）。（历史 46/144/218：0 命中或计数不符一律先怀疑判据 —— 本轮正是「先写判据、后 grep 实际写法」。）事实（机器可查，两轮红）：① 首跑报「未核准形态」× 2 种（源产物的逐轮叙述段里引用了**更早轮次的映射集**与**更早轮次的每轮标识**，而白名单只列了四个更早轮次 ⇒ 覆盖完整性判成「实读 8 种 / 被覆盖 6 种」）；② 「非源侧当前轮的小写路径形态必须为空」这条判据把**在册历史引用目录**（更早轮次的运行目录）判成违规；③ 二跑又报「待重渲染内容段里的小写两轮前形态」——该段在定稿阶段被**整体重渲染**，build 期含旧引用属设计内状态。**危害**：若不修就放行，派生器会带着**上一轮的白名单**去滚本轮产物 —— 源产物里的本轮形态会被判「未核准」或静默漏滚（历史 186/199 的假绿族：产物「看起来完整」，记录的却是上一轮的轮次）。修法 = ① 白名单按**实际形态枚举**补全并写明每条白名单的**语义理由**（含「只出现在待重渲染内容段」这一类）；② 「须为空」型判据改为**显式小集合 + 历史引用白名单**，并配**成对判别力合成对照**（含两轮前形态的合成行必须被报出、含源侧当前轮形态的合成行必须不被报出）；③ 给「待重渲染内容段」立**具名豁免**，且断言该豁免**非空**（否则豁免被架空，历史 57/68/190）；未放宽任何期望值。

2. **派生器的「裸名盲区残留」判据范围过宽：把待整体重渲染的内容段也算进交付面**（判据侧缺陷；失败点在写出任何交付产物之前，未产出错误产物）。（历史 81：判据范围必须与语义一致 —— 这是同族缺陷的第 N 次再现。）事实（机器可查）：派生器首跑报「rowdata 产物仍残留上一轮的裸脚本名」，而该命中落在 rowdata 的**逐轮内容段**（REWORK / PRERUN_FIXES / PENDING）—— 该段由定稿器用本轮内容模块**整体重渲染**，build 期仍是上一轮叙述属设计内状态。**危害**：为消掉这条假红而删掉判据，会让「裸脚本名盲区」（机械滚动永远碰不到 `mk*` 这类裸名）**永久失明**。修法 = 判据**分两处夹**：① 派生器只查**保留区**（内容段之外，按段边界锚点切分并打印两侧命中数作正向对照）；② 定稿器侧新增**整产物级**自检（重渲染之后断言「无上一轮裸脚本名残留」）—— 两处口径互补，既消假红又保住判别力。

3. **残留扫描的豁免集合漏了「按设计内嵌合成判别力对照串」的产物 ⇒ 把合法的合成夹具误报成真残留**（判据侧缺陷；失败点在写出任何交付产物之前，未产出错误产物）。（历史 47/190：守卫脚本自身按设计含轮次号；「必须为空」型判据的豁免要**显式 + 逐条断言真含该引用**。）事实（机器可查）：派生器首跑报「产物残留两轮前小写引用」，违规集合的**唯一**成员是**新写的体检探针** ——它里面那处引用是**合成判别力对照夹具**（用来证明「须为空」判据有牙齿），以及一处**锚点字面量**。**危害**：为消掉这条假红而把该文件从扫描范围里去掉（或收窄判据形态），会让真正的「运行期产物指向上一轮」静默通过。修法 = 把豁免升级为**具名 + 逐条给语义理由的判定函数**：派生器自身要求「无路径形态」（其命中仅作判据/读数标签）；体检探针要求「**每一条**命中行都带合成/锚点标记」。

4. **豁免判据自身的两处写错：形态判得过严 + 判据字面量自指命中**（判据侧缺陷；同一判据站两次迭代，均在写出任何交付产物之前被自身断言拦下）。（历史 47/218：判据里的字面量会**自指命中**；历史 75/98：守卫必须有牙齿。）事实（机器可查）：二跑报「豁免范围内的命中行缺设计内标记」，根因是判据写成「命中必须全部落在残留扫描段**之后**」，而该脚本在**滚动读数行与 docstring** 里合法地引用了同一轮次号；三跑报同一站仍不合规，根因是**判据行自身**就含被搜索的「路径形态」字面量 ⇒ 判据自指命中、恒判不合规。**危害**：这类「必须为空」型判据一旦口径错，方向是**越错越像合规**（历史 98/187 的指纹）；而自指命中会让它**恒红**，靠放宽到「只要文件里有一处合法命中就通过」来消红则等于废弃判据。修法 = ① 形态判据改为按**语义**取（「该文件不得把两轮前轮次用作**路径形态**」，而不是按位置切段）；② 判据字面量**拆分构造**（`"r" + 数字 + "-"`），并在注释里写明「拆分是为了避免自指命中」；③ 保留「豁免非空」断言（本轮实测豁免文件真含 N 处命中）以防豁免被架空。
