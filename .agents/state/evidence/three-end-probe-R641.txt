三、三端可达性（**先剥离代理环境变量**；空体 POST = 参数校验前置失败、无副作用）
------------------------------------------------------------------------------
  代理污染事实（探针侧）：环境里 `HTTP_PROXY` = `HTTPS_PROXY` = `http://127.0.0.1:7897`（本地代理），
      未剥离时对回环地址的请求会被代理截走：`5173/5174` 回 **502** 且响应带 `Proxy-Connection: keep-alive` 标记。
  ① aap-admin dev：GET `http://127.0.0.1:5174/` → **200**，正文含 `<title>AAP 管理端</title>`（594 B，vite dev 首页）；
     POST `http://127.0.0.1:5174/api/v1/auth/sms/send`（body=`{}`）→ **400**，响应头含 **小写** `x-trace-id: 20a8f976…`，
     包体 = 后端五键包络（E-1001 / 参数校验失败 / data:null / traceId / details）⇒ **管理端代理段端到端可达**（与 R640 同结论，本轮在无代理条件下复证）。
  ② aap-client dev：GET `http://[::1]:5173/` → **200**（833 B，uni-app H5 首屏，含 `/@vite/client`），
     POST `http://[::1]:5173/api/v1/auth/sms/send` → **400** + 小写 `x-trace-id: 9403a1ad…` ⇒ **客户端代理段端到端可达**（**本轮新增**）；
     `http://[::1]:5174/` 同形 200 / 代理 POST 400（另一个 uni 进程，同一客户端工程）。
     注意地址族：客户端 dev **只绑 IPv6 环回**，对 `http://127.0.0.1:5173/` 是 `curl exit 7`（连接被拒）——**不是服务不可用**。
  ③ 直连后端对照：POST `http://127.0.0.1:8084/api/v1/auth/sms/send` → **400**，响应头 `X-Trace-Id: 068cfb18…`（**大写 X**）
     ⇒ 与经 vite/http-proxy 的小写 `x-trace-id` **可区分**，证明 ①② 的请求确实穿过了前端代理。
  ④ actuator（无凭据只读）：`/actuator/health` → **200** `{"groups":["liveness","readiness"],"status":"UP"}`（两实例同）；
     `/actuator/info` → **200** `{}`；`/actuator/mappings` → **401 E-1902**（被安全过滤器挡）
     ⇒ 正面：两实例**健康**（不是僵死进程）；负面：**无法**从运行实例读已注册路由表，故 ⑤ 的集合差异只能由 class 加载面推出。
  ⑤ 负向对照：未监听端口 `5199` → `curl exit 7`（连接被拒）；`/api/v1/__no_such_path__` → **401 E-1902**（与真实路径同答）
     ⇒ 沿用 R640 结论：**路由探测不能用于判「实例是否含最新端点」**（安全过滤器先于路由），按纪律**未获取/未伪造任何凭据**。

四、本轮探针判据修正 / 留痕文本修正（**返工留痕 3 处**，均在 $TEMP 取证脚本与留痕文本侧；装置链本体零重跑）
------------------------------------------------------------------------------
  (1) **代理环境未剥离 ⇒ 假发现**：首版探针直接 curl 回环地址 ⇒ 5173/5174 均 **502**，若据此写「客户端 dev 不可用」即为假发现；
      指纹 = 响应带 `Proxy-Connection: keep-alive`（真 dev server 不会输出该头）+ 环境变量里存在本地代理。
      修法：探针内 `unset HTTP_PROXY HTTPS_PROXY …` 后复探（复探后 5173/5174 均 200）。**同一缺陷的第二形态**：
      第二版把 `--noproxy *` 的 `*` 未加引号 ⇒ 被 glob 展开成当前目录文件名 ⇒ 代理未被剥离、**5174 也变 502**（同一处判据的第二次踩）；
      正解 = 用 `unset` 或给通配符加引号，并对**已知可用的对照端点**（5174）同时断言 200，作为探针有牙齿的正向对照。
  (2) **跨源比对两侧未走同一归一 ⇒ 31 条假发现**：磁盘侧类名剥掉了 `com.hioas.aap.` 前缀、histogram 侧是全限定名 ⇒

      修法：两侧同用**全限定点分名**（同一归一函数）后复跑 ⇒ 真实差集 3 / 2（见 二⑤）；正向对照 = 「已加载 28 > 0 ∧ 磁盘 31 > 0」。
