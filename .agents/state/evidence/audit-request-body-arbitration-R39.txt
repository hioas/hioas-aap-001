### 两套门禁为什么看不见（skill 坑 43 / 62 / 73）
  · 契约测试：只把**真实响应**与各模型自己的 JSON Schema 比对；请求模型 schema 的`additionalProperties: true` + 无 required 校验 → 字段名写错/多写都放行；
  · 覆盖门禁：只比「方法 + 路径」注册表；
  · 客户端 TS 与 openapi.yaml 不被任何测试读取/执行。
