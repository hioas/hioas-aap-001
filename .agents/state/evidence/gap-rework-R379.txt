1. **前置核对脚本的锚点写错（判据口径与源文件实际形态不符）⇒ 0 命中、响亮拦下派生链**（历史 205/218/225：锚点必须回**实际产物/源文件**核对，不得按记忆或按上一版脚本类推）。事实：派生前的形态/锚点前置核对脚本里有一条锚点写成「driver 引用了上一轮的 **failraw**」，而源文件里该形态**根本不存在** —— driver 只引用上一轮的 **rcseq**，failraw 由跨轮比对脚本引用⇒ 该条锚点命中 0 次、脚本以非 0 退出。**崩溃方向正确**（响亮失败远好于把错锚点带进派生链，历史 175 正例）。修法 = 回源文件核出真实形态（`EV / "audit-regression-<上一轮>-failraw.txt"` 出现在跨轮比对脚本、rcseq 出现在 driver），并把「0 命中先怀疑判据」写进该脚本的注释。

2. **结束标记判据写成字面量，而源码里是格式串 ⇒ 假 FAIL**（历史 46/218/225 族）。事实：显式重写产物生成器对生成物取证脚本断言「结束标记保留」时，判据写的是**字面量**`GAP_GENPROBE_<本轮>_END`，而该标记在源码里由 `"GAP_GENPROBE_%s_END" % ROUND` 拼出⇒ 判据恒 0 命中、生成器以 rc=1 退出（假失败）。修法 = 判据**双形态**都收（字面量 ∧ 格式串模板），并保留「断言命中」而非放宽为「任意一种形态存在」。

3. **派生后自检的「残留上一轮形态」判据范围过宽（把按设计必须引用上一代的派生/侦察脚本算成残留）＋ 一次性修正脚本误落在产物目录**（历史 81/212/216/244：判据范围必须与语义一致）。事实：自检首版对**全部**产物套「不得残留上一轮（大写/小写）形态」，而派生器与形态侦察脚本按设计就要引用上一代（映射表的键、合成对照串、上一轮目录名）⇒ 一次报出 2 条假 FAIL；同一判据另外扫到误落在产物目录里的**一次性修正脚本**（它按设计引用上一轮源文件名）。修法 = ① 判据窗口按**语义**分层：大写、小写各一个**显式豁免集**（`EXEMPT_UP` / `EXEMPT_LOW`，两者集合不同 —— 因为有的脚本只引用小写形态），并**各配一条「豁免文件确实含该形态」的非空转断言**（否则豁免被架空，历史 57/68/190）；② 一次性脚本移入独立 `oneoff/` 子目录 —— **用布局解决范围问题**，而不是收窄判据（收窄会让同类残留从此静默通过，历史 216-①/③）。
