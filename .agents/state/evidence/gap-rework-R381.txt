1. **逐轮内容生成器的字符串拼接把 `%` 的优先级写错 ⇒ 脚本当场 `TypeError`**（历史 232 的同族：脚本文案拼接的运算符优先级 / 急切求值）。事实：先写下的渲染式是「前半串 + NL + `    %s)` + NL + NL % repr(it)」，于是 Python 先算 `NL % repr(it)` ⇒ `TypeError: not all arguments converted during string formatting`，生成器在**写出任何产物之前**以非 0 退出（响亮失败，历史 175 正例：崩溃远好于静默产出）。修法 = **整串括号化**后再 `%`（REWORK / PENDING 两处渲染同修），并保留「生成器产物自检」这一段。

2. **去轮次化修正项的目标路径写错目录 ⇒ `FileNotFoundError` 响亮拦下**（历史 205/243-②：源 / 目标目录必须回**实际磁盘**核对，不能凭上一轮脚本类推）。事实：派生器的两处「历史自述去轮次化」修正把目标写成 **work 侧**路径，而该产物实际在 **aux 侧**；脚本在**滚动已写完 10 份产物之后**、去轮次化那一步抛 `FileNotFoundError`（滚动是确定性单趟替换，已写产物无错误内容，重跑即一致）。修法 = 目标路径改指 aux 侧，并保留「锚点命中恰好 1 次 ∧ 旧形态 0 残留」双断言（无残留断言会放过「改了一处、另一处还在」）。

3. **判据自指命中：逐轮文案里引用了「被守卫扫描的字面量」⇒ 产物自检假 FAIL**（历史 47/77 的同族：文档 / 文案里的模式字面量会被自己的守卫命中）。事实：「运行前自查修正」段的初版措辞里**照抄了两个被扫描的字面量** —— 一个是上一轮产物的文件名（小写轮次目录形态），另一个是那处常量的**括号形态字面量**；而生成器的产物自检正是按这两者判定 ⇒ 报出 2 条 FAIL、派生链以非 0 退出。**这是守卫正确报警**（产物确实违反了「不得残留上一轮小写引用」这条不变量），不是守卫失效。修法 = 文案改为**等义但不含被扫描字面量**的表述（写「上一轮产物 rowdata_<上一轮轮次>.py」「多行括号形态」），并在条目结尾注明「刻意不写那两个被扫描的字面量」；修后重跑生成器即**就地重写**产物（历史 208：派生脚本必须可重入）。
