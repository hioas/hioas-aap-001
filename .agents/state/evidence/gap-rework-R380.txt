1. **派生前置核对脚本的锚点写成「消费侧的拼接后键名」⇒ 0 命中、响亮拦下派生链**（历史 46/218/225：锚点必须回**实际源文件**核对，0 命中先怀疑判据）。事实：形态/锚点前置核对脚本里有一条锚点写 `FACTS_RUN2_RC`，而执行器是用**循环**落盘的（`FACTS_RUN${R}_RC`）—— 拼好后的键名只出现在**消费侧**（链脚本的门槛判据里写作 `FACTS_RUN2_RC=`，带等号），于是该条锚点在执行器源文件里命中 0 次、脚本以非 0 退出。**崩溃方向正确**（响亮失败远好于把错锚点带进派生链，历史 175 正例）。修法 = 拆成两条按真实形态取的锚点（执行器侧取**循环模板**、链脚本侧取**带等号的门槛判据**）。

2. **生成器模块名含连字符 ⇒ 导入即失败**（历史 232 同族：脚本自身的命名缺陷，与被测对象无关）。事实：逐轮内容模块初版命名为带连字符的名字，而生成器按合法模块名导入 ⇒ `ModuleNotFoundError`、生成器以非 0 退出。**未产出任何错误产物**（当场拦在写入之前）。修法 = 改用合法模块名（下划线），并保留「全部产物 .py 一律 compile 核对」这一派生后自检（历史 235）。

3. **一次性探针误落在产物目录 ⇒ 被「残留上一轮引用」守卫点名**（历史 81/212/216：判据范围必须与语义一致，且优先用**布局**解决范围问题）。事实：本轮为核对形态/纯数字盲区临时写的只读探针（按设计要读上一轮的产物）落在**产物目录**里，被派生器的残留守卫响亮报出（2 处小写上一轮引用），连带「豁免集合 == 期望集合」判据一起转红。修法 = 把一次性工具移入独立 `oneoff/` 子目录（**布局**解决），并让派生后自检按同一布局口径扫描—— 收窄判据会让同类残留从此静默通过。

4. **派生后自检的「非本轮目录引用」判据范围过宽 ⇒ 假 FAIL**（历史 81/218：判据范围必须与语义一致）。事实：跨轮驱动脚本按设计要引用**更早轮次**的抽查脚本源目录（这是「源侧名字按产出它的那一轮取」的既定形态），而自检首版把「一切非本轮的小写轮次目录名」都算成异常 ⇒ 报出 1 条假 FAIL、自检 rc=1。修法 = 显式白名单 + 断言白名单目录**在磁盘上真的存在**（否则白名单被架空，历史 57/68/190），而不是放宽成「忽略所有历史目录」。

5. **专用标记行随「每轮滚动 + 插入」逐轮累积**（历史 208/222：插入型替换必须先去重）。事实：显式重写产物的生成器每轮把标记行插到文件头部，而从不清除旧行 —— 源产物里已有 2 行标记，滚一轮后产物变成 3 行（该累积自引入以来每轮 +1，属「只活在临时目录的工具长期无人复核」的实例）。**本轮为派生前人工复核产物时发现**，未影响任何读数。修法 = 两个生成器都改为「先移除全部旧标记行、再插入恰好 1 行」，并对**产物**断言「标记恰好 1 行」（源里行数只作历史累积读数打印，不作判据）。

6. **台账单一事实源生成器漏注入 `PRERUN_FIXES` ⇒ 消费方 AttributeError**（历史 46/98：消费侧报「缺属性」时先查生成器产物，别先怀疑内容）。事实：该生成器把逐轮内容按三段边界替换注入，而「运行前自查修正」段**位于第一段边界之内**，首版只注入了 REWORK 与断言、漏了它 ⇒ 生成物导入成功但缺该属性，台账写入脚本在**写台账行之后**抛 `AttributeError`（台账行与状态段当时已被写入，属**可重入重写**的中间态：修好后重跑即就地重写，不会留下错内容）。修法 = 生成器补注入该段 + 对**产物**断言「该段恰好 1 处」；判据取「产物含该定义」而不是「消费者不报错」。
