1. **派生器的**正向对照期望值**写错：探针串把「本轮形态」也当成映射区内的待改写项，而映射区只含 4 个轮次 ⇒ 实际改写 4 处、断言写 5 ⇒ `AssertionError` 当场拦下**（判据侧缺陷；产物落盘**正确**，错的是判据本身）。（历史 46/175：异常值 / 0 命中一律先怀疑判据；历史 66/94：注入/对照必须证明自己真的生效。）事实（机器可查）：合成探针（大写三轮 + 映射区四轮 + **边界外两轮** + 小写四轮，见本轮派生脚本的 `ROLL_PROBE_OK` 行）经单趟映射后大写改写 **4** 处（映射区四位数字），末尾「本轮形态」属**边界外**、必须原样保留；小写侧同理 4 处（判据串的字面量按历史 47/218 的纪律**不在此引用**，避免自指命中）。**危害**：期望值写错的正向对照会**长期假红**，诱使作者去放宽断言（削弱守卫）。修法 = 拆成两类断言（映射区内 4 处 / 边界外两种轮次号 **零改写**），**改的是判据，不是期望值**。

2. **「无前缀盲区」的又一处成员：内容里的**裸标签**（`MK` + 三轮数字的常量名）—— 前缀替换与文件名级替换都碰不到它 ⇒ 残留扫描一次报出 98 条命中，其中「内容里的裸标签」属实、必须单列一类显式推进**（覆盖面缺陷；由残留扫描报出，产物尚未进入任何提交）。（历史 224/239：覆盖完整性必须机器核对，不能靠人列举；历史 215：同一事实的多种写法是同步脚本的必踩坑。）事实（机器可查）：首版滚动只覆盖两类形态 —— ① `[Rr]` + 三轮数字（含目录名 / 证据文件名）② **文件名级** `mk`/`MK`/`boot` + 三轮数字；而「常量名里的裸标签」是第三种写法，既无 `r`/`R` 前导、也不在文件名位置。**危害**：漏推进即「产物自述的自身身份停在上一个轮次」而**没有任何断言**可报（历史 12/95 的机器可查形式）。修法 = 把裸标签写进**滚动清单**并逐类断言命中数，再以「替换后残留 == 0」作反向守卫。

3. **残留扫描的判据范围过宽：把「按设计就要读上一轮产物的引导器 / 派生器 / 体检脚本」判成「残留上一轮引用」**（判据侧缺陷；由人工逐条分类发现，非任何断言报出 —— 这正是本项被登记的原因）。（历史 212/216：豁免要写成**显式名单**并断言豁免对象**真的含**该引用；历史 81：判据范围必须与语义一致。）事实（机器可查）：98 条命中里绝大多数落在三类脚本的**读取语句**上（`SRC = T / "<上一轮>-oneoff"`、`roll((SRC / "derivectx_<上一轮>.py")...)`），而它们的存在前提就是引用上一轮。**危害**：若不分类而直接「加豁免」，规则会被架空（历史 57/68/190）；若收窄成「只看本轮交付产物」而不打印分类，下次同类**真残留**会被静默放过。修法 = 范围收窄到**本轮实际交付 / 消费的产物**，同时把全部命中**逐条分类打印**（不删条目、不加豁免）。

4. **执行顺序缺陷：第 39 类「证据产物轮次自述一致性」核对被排在第 38 类「生成物 ⇔ 单一事实源」现场取证**之前** ⇒ 该脚本的「缺失条目全部有解释」判据报 1 条未解释缺失**（流程 / 判据侧缺陷；由该脚本自身的断言响亮报出，**未进入任何提交**）。（历史 217-② 与更早轮次登记的「第 39 类顺序要求」同源：**先产出 → 后核对**；历史 46/222：清单类判据必须区分「本阶段稍后产出」与「真缺失」。）事实（机器可查）：该脚本允许「本阶段稍后产出集合 ∪ 收尾期白名单 ∪ 本文件自身」，而上游取证产物**不在**该集合内 —— 它的定位就是**上游产出**，必须在核对之前落盘。**危害**：若为让它变绿而把该取证加进白名单，则「该取证必须存在」这条不变量会被架空（历史 57/68/190）。修法 = **按顺序重排**（先跑取证、后跑核对）；复跑后 FAIL 由 1 条转 0 条，**白名单条数未变、未放宽任何判据**。

5. **（收尾阶段暴露）向**末行无换行**的文件追加 ⇒ 首条追加行与上一行**粘连** ⇒ 该轮新写条目的标题行被并进上一条正文，行首形态不成立**（脚本侧缺陷；由追加后的**行首形态复核**当场报出，**未污染仓库交付物** —— 该文件是技能参考资料、不在仓库内）。（历史 84：追加前必须先 `[ -n "$(tail -c 1 "$F")" ] && printf '\n'` 补末行换行；历史 146/69：行尾形态一律按字节级手段核对。）事实（机器可查）：追加后「行数增量 == 新增条目数」的断言报 **39 != 40**（差 1 行 = 被吞掉的那一行），`grep -c "^358\.
