2. **前置体检自身的正则锚点写成了「行首锚定」形态：真实产物里该名字是**行内**出现在括号里 ⇒ 0 命中并报「锚点未命中（判据失效）」**（判据侧缺陷；由体检自身的断言当场报出 `PRECHECK_FAILS=4`，**未生成任何产物**）。（历史 218/225：锚点必须回**实际产物**按字节核对，不能按记忆或按行首假设写；历史 46：0 命中先怀疑判据。）事实（机器可查）：锚点写作 `^mk\d+-build\.py` 时命中 0 次，而把行首锚定去掉后命中 **2** 次 —— 即被测文本里的真实形态是「（`mk…-build.py`）」这类行内引用。**危害**：锚点失效会让「定稿器将改写的常量/引用是否真的存在」这条前置保证变成**空转**（永远没人核对），而它本意是防「派生脚本把上一轮的措辞带到本轮」。修法 = 锚点去掉行首锚定，并保留「命中数逐条打印 + >= 1」的正向对照；未放宽任何期望值。

3. **定稿器的「段重写」把段末换行一起吃掉了 ⇒ 产物与下一行**粘连**成非法语句（`invalid syntax`）**（脚本侧缺陷；由**本轮新增的常驻语法核对脚本**当场拦下 —— 该核对的判据是「全部派生产物必须能 `compile()`」，并打印报错行原文）。（历史 232/235/236：产物语法错误会让下游以「看起来像守卫失效」的方式崩。）事实（机器可查）：终点锚点**不带前导换行**（如 `REWORK_SHORT = []`）时，切片 `text[ib:]` 会把下一行直接接在段末文本之后；实测报错行原文为「…）。「）」后紧跟 `REWORK_SHORT = []`」同一行。**危害**：产物落盘后语法错误，若没有语法核对，缺陷会在**下游首次 import 时**以 `SyntaxError` 暴露，或者更糟 —— 被误判成「守卫脚本坏了」。修法 = 终点处**保留恰好一个换行**（按锚点是否自带换行判定），且落盘前 `compile()` 复核（**未落盘**即报出），未放宽任何期望值。

4. **定稿器的「残留」判据过宽：把**裸三位数字**当残留形态，于是命中了本轮新写的说明性文字里的枚举清单（「实测 7 种形态：…」）⇒ 假 FAIL（未落盘）**（判据侧缺陷；由定稿器自身的产物自检断言当场报出）。（历史 81/202/218：判据范围必须与语义一致。）事实（机器可查）：该判据首版用裸三位数字形态 → 命中 1 条，而那条正是**本轮新写的枚举清单**；收窄为带前缀的**轮次引用形态**后命中 0 条，且配了成对判别力对照（合成的**引用形态**必须命中 = True / 合成的**裸数字**必须不命中 = True）⇒ 收窄**不是放宽**。**危害**：过宽的残留判据会把合法自述判成缺陷，诱使作者去改写正确文本、甚至给它们加豁免，最终这条守卫被架空（历史 57/68/190）。修法 = 判据按「轮次**引用**形态」定义（必须带 [Rr] 前缀），未删任何断言。
