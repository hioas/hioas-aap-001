"""R35 抽查：ID 类字段对外类型不变量（string vs number）——第十类契约不变量。

  - 契约测试只读 JSON Schema；schema 里雪花 ID 是 string（避免 JS 精度丢失），

  - **openapi.yaml 从不被任何测试读取**、**aap-client 的 TS 类型从不被任何测试执行**
    → 「openapi/客户端把 ID 声明成 number」对两套门禁完全不可见。

纪律（本轮实测教训）：
  - O 分支第一版只走内联 `properties`，而 openapi 的 model 层是**文件 $ref**（410 处 ref）
    → 「openapi ID 字段 0 个」是**我脚本的假阴性**（O1 的 PASS 是空转假绿）。
    靠正向对照 O0（解析到的节点数）才发现 → 坑 46「每个分支都要有正向对照」。
  - 例外的豁免必须显式列名 + 设条数上限（坑 68），否则「唯一一个 integer」会被悄悄放过。

只读：不写仓库任何文件；带正向对照 + 内存内注入缺陷的判别力自检。

NON_ID_SUFFIX = ("valid", "solid", "rapid", "paid", "hybrid", "void")


def is_id_name(name: str) -> bool:
    low = name.strip().lower()
    if low in ("id", "ids"):
        return True
    if low.endswith("_id") or low.endswith("ids"):
        return True
    if low.endswith("id") and not low.endswith(NON_ID_SUFFIX):
        return True
    return False


def type_set(t) -> set:
    if isinstance(t, str):
        return {t}
    if isinstance(t, list):
        return {x for x in t if isinstance(x, str)}
    return set()


results = []


def check(name, ok, detail=""):
    results.append((name, bool(ok), detail))

schema_ids = {}          # (file, prop) -> (typeset, description)
nonid_numeric = 0
for d in SCHEMA_DIRS:
    for f in sorted(d.glob("*.json")):
        doc = json.loads(f.read_text(encoding="utf-8"))
        for prop, spec in (doc.get("properties") or {}).items():
            if is_id_name(prop):
                schema_ids[(f.name, prop)] = (type_set(spec.get("type")), spec.get("description") or "")
            elif type_set(spec.get("type")) & {"integer", "number"}:
                nonid_numeric += 1

    if isinstance(node, dict):
        props = node.get("properties")
        if isinstance(props, dict):
            inline_props.append(path)
            for p, spec in props.items():
                if isinstance(spec, dict) and is_id_name(p):
                    openapi_ids[path + "/" + p] = type_set(spec.get("type"))
        for k, v in node.items():
            walk(v, path + "/" + str(k))
    elif isinstance(node, list):
        for i, v in enumerate(node):
            walk(v, path + f"[{i}]")


walk(doc)
