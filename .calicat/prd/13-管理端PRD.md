# 管理端PRD

# PRD — 管理端（运营商务 + 技术运营 Web 后台）

> 对应模块：M8 审核、M9 合同与结算、M10 编译管理与确认、M11 new-api 同步、M12 用量统计，外加状态看板首页与技术运营配置中心。
> 载体：桌面 Web（Vue3 + Element Plus + ECharts）。角色：运营商务、技术运营、超级管理员。

## 0. 定位与设计原则

管理端是运营方的单一操作面板。原则：一屏看清阶段（首页看板回答"每个供应商卡在哪一步、卡了多久"）；状态驱动动作（按后端 allowed\_actions 渲染）；危险操作三道闸（编译校验→人工确认→幂等写入+回读）；全量审计；诚实边界（措辞"未发现与宣称模型不一致的迹象（置信度：高/中/低）"）。

## 2. 导航结构

登录 → 状态看板首页 →（供应商管理 / 检测中心 / 报价与审核 M8 / 合同与结算 M9 / 编译与确认 M10 / new-api 同步 M11 / 用量统计 M12 / 配置中心 / 系统管理）。

供应商管理：列表、凭证管理、供应商 360 详情。检测中心：检测任务、检测报告、检测项阈值配置。报价审核：待审报价池、报价审核台、历史对比。合同结算：合同管理、打款记录、结算台账。编译确认：编译任务、人工确认台。同步：同步任务、渠道映射、日志审计。用量：小时用量、供应商对账、成本看板。配置中心：检测项阈值、报告模板、任务监控。系统管理：账号角色、审计日志、new-api 连接配置。

菜单按权限点动态过滤：技术运营看不到合同写操作；运营商务看不到检测配置/报告模板/审计日志/new-api 连接。

## 3. 全局交互规范（所有列表页统一）

筛选区（可折叠，高频默认展开，条件写 URL query）；排序（后端排序，多列 Shift）；分页（服务端，20/50/100）；列配置（显示隐藏持久化）；批量操作（复选框+批量操作条，不满足项置灰）；导出（异步任务，超 5 万行转下载中心，记审计）；空态/骨架屏；行操作（主操作 ≤2 外露，危险红色二次确认）；审计埋点。

状态徽章色彩：蓝=进行中（DETECTING/审核中/同步中）；橙=待操作（QUOTE\_SUBMITTED/CONTRACT\_PENDING/部分失败/人工复核）；绿=成功（DETECT\_PASSED/已通过/已同步/已启用/已上架/供货中）；红=异常（DETECT\_FAILED/已驳回/同步失败/已停用）；灰=终态（已终止/已归档）。

## 4. 首页：状态看板

① 顶部 KPI 卡带（6 张）：在途供应商/待审报价/待签合同/待打款/本周上架/异常告警（红色高亮），点击跳对应筛选列表，含环比。
② 阶段漏斗/泳道看板（主干）：列=供应商生命周期阶段（待提交凭证/检测中/检测未通过/检测通过待报价/待审核报价/待签合同/已签约待打款/已上架供货中）；卡片显示供应商名/主要模型/停留时长/负责人，按停留时长排序，超 SLA 标红角标。
③ 待办队列：Tab（待我审核/待处理合同/待记录打款/待同步/复测告警），每条动作类型/供应商/提交时间/等待时长/\[去处理]。
④ 今日运营动态时间线（操作审计流只读）。
⑤ 用量/成本迷你图（近 24h 折线 + Top 供应商柱状）。

批量操作：批量催办（合并发短信去重限频）、批量分配负责人、导出看板快照。技术运营隐藏合同/打款 Tab，重点关注复测告警。

## 5. M8 审核（报价单审核：技术指标复核 + 价格审核）

待审报价池列表字段：报价单号/供应商/模型数/提交时间/等待时长（超 SLA 标红）/检测总分结论/当前状态/审核人/操作（领取/查看）。

报价审核台（左右分栏）：左栏证据区只读（供应商档案摘要、检测报告结论卡含总分/三态/置信度/D7 一票否决、报价单模型清单与有效期、历史报价）；右栏决策区（价格明细复核表逐模型：输入/输出/缓存读/写 5min/写 1h/图片音频价、峰谷倍率、阶梯档位、与基准价偏差%；技术指标复核区；决策 通过/驳回/备注；审计时间线）。

筛选：供应商关键字/状态/提交时间/检测结论/模型/等待时长 SLA/审核人。

批量操作：批量领取、批量驳回（同一原因）、批量导出；**不提供批量通过**（通过触发合同+编译链式副作用，必须逐单确认）。

权限差异：驳回/通过/生成合同仅运营商务+超管；技术运营仅技术指标复核；历史对比全员。

异常：报价含无效模型（new-api 未注册）阻断通过；边界冲突后端拒绝流转；并发审核乐观锁；检测报告"人工复核"未处理则通过按钮置灰；供应商撤回则本单作废；合同服务不可用则进入重试队列不重复生成。

## 6. M9 合同与结算管理

合同管理列表（统一规范）。合同详情/签署确认：合同头信息（合同号/供应商/关联报价单/金额概要）、合同文本区（系统生成 PDF+下载）、附件区（我方盖章件/供方盖章件上传预览）、签署状态条（我方✓/供方✓/时间戳）、操作区、审计时间线。打款记录页：筛选+列表（打款单号/供应商/金额/币种/打款日/凭证/状态）+ 行操作+新增。结算台账（按供应商聚合的合同—打款—上架对账视图）。

合同实体：合同号 `HT-{YYYYMMDD}-{序号}`、供应商、关联报价单、金额概要（标注"按实际用量结算"）、签署渠道 OFFLINE（预留 ONLINE）、我方/供方签署状态、合同文件、盖章件、有效期、状态（待签/已签/已归档/已作废）。

打款记录：打款单号/供应商/金额/币种/打款日期/打款方式/凭证附件/settlement\_status（未打款/已打款/已确认）/备注。**不做资金流转，仅记录。**

异常：合同生成失败保持待签提示缺失字段；上传件超限预校验；打款金额偏差过大二次确认；重复打款单号拦截；合同作废但已打款阻断；供方迟迟不签超 SLA 催办。

## 7. M10 编译管理与确认（报价单 → billingexpr）

编译链路三道闸门：①编译 → ②模拟求值校验（样例向量比对预期）→ ③人工确认（三栏对照）→ 确认后才写 new-api option。

编译任务列表：报价单号/供应商/模型数/编译状态/校验结果/确认状态/操作。

人工确认台（三栏对照）：① 填单原文（业务语言报价、输入/输出/缓存、峰谷/阶梯规则）；② 编译产物（billingexpr 表达式逐模型、tier 标签、expr\_version、source\_hash）；③ 模拟账单（样例向量预期 vs 实算，基础/缓存/阶梯/时段/组合五类用例，差异高亮）；④ 校验结论；⑤ 决策（确认写入/退回修改）；⑥ 变更快照 diff；⑦ 审计时间线。

编译产物字段：expr\_version（v1）/expr/tier\_labels/source\_hash/verified/verify\_report。

模拟校验用例：基础（prompt=1000/completion=500）；缓存命中（p=800+cr=200 无重复计费）；阶梯边界（len=512000 vs 512001）；时段边界（09:00/08:59/12:00/18:00 半开区间）；组合（len=600000@10:00 命中 t1.peak）。

边界冲突检测（编译前）：时段重叠/阶梯空洞或重叠/倍率≤0 或 NaN/单价为负 → 拒绝。

批量：批量触发编译（只编译不写库）、批量导出表达式；**不提供批量确认写入**（写生产逐条签字）。

权限：人工确认写入需技术运营签字或超管；运营商务仅查看/退回。

异常：编译失败定位字段；模拟校验不一致 verified=false 禁止确认；billingexpr 不支持变量绑定则全量内联展开；source\_hash 幂等；变更已上架模型价格强制展示 diff 快照保留旧快照。

## 8. M11 new-api 同步（建渠道/写价/启停）

集成路径（全部既有管理 API）：建渠道 `POST /api/channel/`（ChannelSensitiveWrite）；改渠道 `PUT /api/channel/`（ChannelWrite）；写价格 option `billing_setting.billing_expr[model]`；同步模型 `POST /api/models/sync_upstream`；批量启停 `tag/enabled`/`tag/disabled`。

字段映射：Key=供应商 apikey（解密后写入，展示脱敏）；BaseURL=测试端点；Models=模型清单逗号分隔；Name=`AAP-{简称}-{序号}`；Group=定价分组；Tag=供应商标识；Priority/Weight 审核后设定；Setting 不覆盖。

同步任务列表：同步单号/供应商/动作类型（建渠道/改渠道/写价/启停）/目标渠道/状态（待同步/同步中/已同步/部分失败/已回滚）/幂等判断/回读校验/重试次数/操作人时间。渠道映射页：供应商↔渠道对照（渠道名/channel\_id/tag/group/模型/状态/最近同步）。同步日志与审计：请求摘要脱敏/回读结果/前后值快照。

同步失败处理与回滚：读 source\_hash 判断变更 → 建/改渠道 → 写价格 → 回读校验比对 → 一致置已同步/不一致进入重试（指数退避 ≤N 次）→ 耗尽告警保留现场 → 可回滚（渠道已建价格失败→停用/删除；改价失败→写回旧快照）。

批量：批量重试、批量启停（tag/enabled|disabled）、批量导出。

异常：鉴权失败阻断提示 Token 无效/权限不足；渠道已存在转改渠道；价格写入成功但渠道未启用→部分失败；回读不一致不置已同步；new-api 升级接口变更→适配器隔离+降级人工。

## 9. M12 用量统计可视化

小时用量主视图：筛选（供应商/渠道/模型/时间范围默认近 24h/粒度小时天）→ 概览卡（总 token/总费用/请求数/缓存命中率）→ 折线图（token 与 quota 随时间）→ 表格（渠道×模型×小时：输入/输出/缓存 token/费用/请求数）→ 计费构成（按 tier 标签分布）。

供应商对账：供应商/周期/渠道数/模型数/总 token/总费用/缓存命中/环比/导出。成本看板：Top 供应商柱状、成本趋势、异常用量告警。

数据源：new-api Log 表（channel\_id/model\_name/created\_at/prompt\_tokens/completion\_tokens/quota）+ SumUsedQuota 按渠道聚合；缓存命中 token 缺口 F8 → 方案 C 自建小时用量表；计费构成靠 tier\_labels 落日志。

异常：聚合延迟标注"数据更新于 HH:mm"；缓存字段缺失标"未采集"；用量突增突降触发告警；重聚合幂等 upsert。

## 10. 技术运营配置中心

检测项与阈值：D1–D8 权重（默认 D1 .10/D2 .15/D3 .10/D4 .10/D5 .10/D6 .10/D7 .35/D8 0）、pass\_score 70、一票否决（D7<40）、人工复核区间 ±10、各检测项启停、分项阈值。权重和=1 校验，保存写审计，提示"修改对新任务生效，已生成报告不变"。

报告模板：Logo/标题/章节顺序/是否展示原始数据/免责声明文案/输出格式/四段式解释文案。保存时校验不得出现"保证为真模型"措辞。

任务监控：检测任务监控（排队/执行中/失败/耗时/重试/卡住）、同步任务监控、聚合任务监控、告警中心（一票否决/复测降级/同步失败/用量异常）。操作：重跑、终止卡住任务、查看日志（脱敏）。

## 11. 全局非功能与审计

审计（所有状态流转/凭证访问/价格变更/同步操作，含前后值，不可删改）；凭证安全（明文仅超管二次验证+审计，接口脱敏）；权限（前端渲染+后端二次校验）；性能（列表 P95<500ms、看板 KPI 缓存≤60s、导出异步）；可用性（同步失败进重试队列不阻塞主流程、检测故障不阻塞报价可人工放行）；合规（措辞不宣称保证为真、个人信息脱敏）。

## 12. 验收标准（管理端）

B1 首页一屏可见供应商阶段与停留时长；B2 报价通过自动发起合同且不可批量通过；B3 列表页统一规范；B4 编译未过模拟校验时确认写入不可用；B5 同步幂等+回读+重试+回滚；B6 tag 批量启停生效；B7 缓存命中 token 采集展示缺失标注；B8 权重调整仅对新任务生效；B9 全部状态变更/凭证访问/价格变更/同步有审计含前后值；B10 权限差异（技术运营无法通过/打款/上传合同，运营商务无法改检测配置）。
