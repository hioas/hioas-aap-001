# 项目总览 — hioas-aap

> AAP = Automated Application Processing（自动化进件）。面向 LLM API 转售业务的上游供应商进件 → 模型指纹检测 → 报价 → 合同 → 自动上架 new-api → 用量核算全流程闭环系统。

## 一句话定位

把"模型供应商接入"从人工拉群、Excel 报价、手工配 new-api 的脏活，改成供应商自助填表 → 系统自动验真 + 自动编译计费表达式 → 自动上架的标准流水线。

## 业务背景

运营方经营 new-api LLM 网关转售业务，上游有多个模型供应商。当前接入需人工完成 6 环节：商务对接（微信/邮件）、测试端点收集、质量验证（人工抽测）、报价（Excel/微信）、上架（手工建渠道配倍率）、对账（事后翻日志）。

## 核心价值主张

* 验真——多维指纹交叉验证模型真实性与服务质量，输出可解释报告。
* 编译——供应商填的业务报价自动编译为 new-api billingexpr 表达式，零人工翻译。
* 闭环——检测通过→短信通知→在线报价→电子合同→自动上架→按小时用量核算，全链路可追溯。

## 角色

供应商（提供方，小程序/H5 自适应）：注册登录、提交测试凭证、查看报告、填写报价、签署合同。
运营商务（需求方，管理端 Web）：审核检测、审核报价、发起合同、打款、上架 new-api。
系统（后台任务）：检测执行、报告生成、短信通知、表达式编译、同步 new-api、小时用量统计。
