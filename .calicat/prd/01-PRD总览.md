# PRD 总览 — hioas-aap

## 1. 术语表

| 术语                      | 定义                                             |
| ----------------------- | ---------------------------------------------- |
| **提供方 / 供应商**           | 向上游提供模型 API 能力的实体（原厂、渠道商、中转商）                  |
| **需求方 / 运营方**           | 经营 new-api 转售业务的一方（本系统使用方），即"甲方"               |
| **进件**                  | 供应商从注册到上架可用的全过程                                |
| **凭证（Credential）**      | 供应商提供的测试三要素：base\_url + api\_key + model\_list |
| **检测任务（Detection Job）** | 针对一组凭证执行全部检测项的一次运行                             |
| **检测项（Probe）**          | 单个维度的探测，如 TTFT、一致性                             |
| **检测报告（Report）**        | 检测项结果 + 打分 + 解释的汇总产物                           |
| **报价单（Quote）**          | 供应商针对若干模型提交的价格方案                               |
| **明细行（QuoteItem）**      | 报价单中单个模型的价格条目                                  |
| **计费表达式（BillingExpr）**  | new-api 的可执行计费公式字符串                            |
| **上架（Publish）**         | 在 new-api 创建渠道 + 写入价格，使模型可被调用                  |
| **用量（Usage）**           | 按渠道×模型×小时聚合的 token 消耗与费用                       |

## 3. 功能模块地图

```
hioas-aap
├── M1 账号与认证（手机号注册/登录、微信授权登录、管理端账号）
├── M2 供应商档案（企业信息、资质上传）
├── M3 凭证管理（提交凭证、加密存储+脱敏、预检）
├── M4 检测引擎 ★（TTFT/P50/一致性/RPM/TPM/缓存命中/模型指纹/真实源）
├── M5 检测报告（分项打分+总分、模板渲染、导出）
├── M6 通知（短信/站内信/状态变更）
├── M7 报价（报价单编辑、时段价/阶梯价/缓存价、提交撤回）
├── M8 审核（技术复核、价格审核、报价对比）
├── M9 合同与结算（生成/上传/签署、打款记录、归档）
├── M10 计费编译 ★（报价→billingexpr、模拟求值校验、人工确认）
├── M11 new-api 同步（建渠道/改价格/启停、幂等、日志审计）
└── M12 用量统计（小时级聚合、自建用量表、对账视图）
```

★ = 核心模块，详见专项 PRD。

## 4. 全局状态机（供应商生命周期）

**状态流转由后端统一管理，前端只渲染当前状态允许的动作。**

| 状态                   | 供应商可见动作    | 运营可见动作         |
| -------------------- | ---------- | -------------- |
| `PENDING_CREDENTIAL` | 提交凭证       | 代填、催办          |
| `DETECTING`          | 查看进度       | 查看进度、终止        |
| `DETECT_FAILED`      | 修改凭证、重新检测  | 查看原因、人工放行（需备注） |
| `DETECT_PASSED`      | 填写报价单      | —              |
| `QUOTING`            | 保存草稿、提交    | 催办             |
| `QUOTE_SUBMITTED`    | 撤回         | 领取、驳回、通过       |
| `CONTRACT_PENDING`   | 查看合同、上传盖章件 | 上传合同、发起签署      |
| `SIGNED`             | 查看         | 确认签署           |
| `PAID`               | 查看         | 记录打款           |
| `PUBLISHED`          | 查看看量       | 同步、改价、停用       |
| `SUSPENDED`          | 查看原因       | 恢复             |

## 5. 非功能需求

| 类别          | 要求                                                                           |
| ----------- | ---------------------------------------------------------------------------- |
| **安全-凭证**   | apikey 落库 AES-256 加密（密钥与库分离）；接口返回一律脱敏（sk-\*\*\*\*abcd）；查看明文需超管 + 二次验证 + 审计日志 |
| **安全-SSRF** | 检测引擎出站请求经专用代理，禁用内网网段、禁用非 http/https、限制重定向次数、限制响应体大小                          |
| **安全-限流**   | 检测压测档位有硬上限；同一凭证并发检测任务 ≤1；供应商每日检测次数配额                                         |
| **性能**      | 检测任务异步执行，单次检测（含压测）≤ 15 分钟；管理端列表接口 P95 < 500ms                                |
| **可用性**     | new-api 同步失败不影响主流程（进入重试队列）；检测引擎故障不阻塞报价流程（可人工放行）                              |
| **审计**      | 所有状态流转、凭证访问、价格变更、同步操作留审计日志                                                   |
| **合规**      | 报告措辞不得宣称"保证为真模型"；合同需双方主体信息完整；个人信息脱敏                                          |
| **兼容**      | 供应商端一套代码适配小程序 + H5（响应式），管理端 Web                                              |

## 6. 埋点与指标

| 事件                                                              | 用途           |
| --------------------------------------------------------------- | ------------ |
| `provider_register_success`                                     | 注册转化率        |
| `credential_submitted` / `credential_precheck_failed`           | 凭证质量         |
| `detection_started` / `detection_finished` / `detection_failed` | 检测成功率、耗时分布   |
| `report_viewed` / `report_exported`                             | 报告使用度        |
| `quote_created` / `quote_submitted` / `quote_rejected`          | 报价转化与驳回原因    |
| `contract_signed` / `payment_recorded` / `published`            | 漏斗           |
| `sync_success` / `sync_failed` / `sync_rolled_back`             | 同步可靠性        |
| `compile_verify_failed`                                         | 编译质量（关键质量指标） |

**北极星指标**：供应商从注册到上架的中位时长（目标 ≤ 3 天，其中系统侧耗时 ≤ 2 小时）。
**质量指标**：检测通过后 30 天内被复测发现降级的比例（期望 < 2%）。
