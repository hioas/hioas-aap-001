# 前端原型说明

# 前端原型 — hioas-aap

供应商端（小程序 / H5 自适应）+ 管理端（Web）的可交互原型。打开 index.html 可一次走查全部 11 屏。

## 1. 设计决策

### 1.1 Surface 选择

* 供应商端：Operate / Configure —— 任务流导向，顶部步骤条、表单分组、待办优先、底部固定操作条。
* 管理端：Monitor / Operate —— 高密度，漏斗 + 流水线看板 + 表格。

### 1.2 信息架构原则

* 供应商端不暴露技术细节——报价页只给业务语言（峰谷、阶梯），把"计费表达式"藏在一句示例里。
* 管理端把两件事并排放——报价审核页三栏：供应商填了什么｜网关会怎么算钱｜上下文。让"翻译"可见、可审。
* 状态可回溯——工作台用时间线、签署页用进度条。

### 1.3 视觉系统

| Token | 值                             | 理由                                |
| ----- | ----------------------------- | --------------------------------- |
| 主色    | 深青 oklch(0.52 0.085 197)      | 避开 AI 产品默认 indigo/violet，偏工业/基建气质 |
| 强调色   | 琥珀 oklch(0.70 0.145 62)       | 只用于"需要你操作"（待办卡、主 CTA、峰时标识）        |
| 语义色   | 绿/黄/红/蓝                       | 状态可辨，色盲友好（色点 + 文字标签）              |
| 字体    | PingFang SC + ui-monospace 数字 | 数值用 tabular-nums 对齐               |
| 圆角    | 6/10/14 px 三级                 | 形成层次                              |
| 点击目标  | 最小 44px                       | 移动端可用性底线                          |

刻意避免的 AI 设计通病：无渐变背景、无玻璃拟态、无 emoji、无三件套卡片墙、无巨型装饰数字、无紫色。

## 3. 原型覆盖的关键状态（不止顺利路径）

| 端    | 已覆盖状态                                                              |
| ---- | ------------------------------------------------------------------ |
| 供应商端 | 草稿态·检测中·检测通过·待办提醒·驳回后修改·价格附件二次确认                                   |
| 管理端  | 待审核·一票否决(指纹 38 分)·同步部分失败(渠道成功/价格 403)·已回滚·停用渠道·用量为 0·复测降级告警·峰时溢价成本 |

* vendor 06 → 报价与合同结算PRD（M7）+ 商业编译规则
* vendor 07 → 报价与合同结算PRD（M9）

* admin 02 → 管理端PRD（M8）+ 同步用量PRD（M10）

## 5. 实现注意

* 自适应：供应商端 body max-width 430px 居中，窄屏自动铺满。
* 底部操作条 position fixed + max-width 居中，小程序端需 env(safe-area-inset-bottom)。
* 数值用 .num/.mono 等宽对齐。
* 表单校验规则见供应商端PRD字段规格表。
* 样例数据为虚构。
