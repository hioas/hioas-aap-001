## 统计与纪律

| 里程碑 | 任务数 |
| --- | --- |
| M4 | 12 |
| M5 | 12 |
| M6 | 12 |
| **合计** | **36** |

**执行纪律**（沿用既有）：

1. 每条任务先取**红基线**（契约测试红在能力缺失），再实现转绿（宪法 D-02）。
2. 证据文件**不用固定名 + `tee`**（D-03）；中间态加阶段后缀。
3. 新增能力**同时收紧门禁**（D-04），含反向断言。
4. 端点数变更必须同步：生成器 → `endpoints.json` → `openapi.yaml` → `EndpointCoverageTest`。
5. 提交**逐路径显式添加**，禁止 `git add -A`（D-06，本仓库多会话共用）。
6. 未实测的结论不得写成「已定」（D-07 / research §5）。
