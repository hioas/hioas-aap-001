# constitution · 项目宪法（不可协商项）

> 本文件是 `specs/**` 全部规格的上位约束。任何 spec / plan / tasks 与本文件冲突时，以本文件为准。
> 修订需显式记录于 §7 变更登记。

---

## 1. 项目身份

**AAP**（AI 供给接入平台）是 new-api 的**外挂进件与治理系统**：
把「AI 模型供应商」从提交凭证一路送到「在 new-api 上可调度、可计费、可结算」的状态，
并对在架供给做持续质量与价格治理。

new-api 是**外部系统**，不是我们的代码库。

---

## 2. 红线（违反即拒绝合并）

| # | 红线 | 含义 |
| --- | --- | --- |
| **C-01** | **new-api 零源码改动** | 全部集成通过其既有管理 API / 只读 DB 完成。禁止 fork、禁止 patch、禁止依赖未公开接口。 |
| **C-02** | **未经模拟求值校验，禁止写入生产定价** | 编译产物必须通过样例向量实算后才允许写入 new-api（编译闸门②）。此闸门**任何自动化等级都不得跳过**。 |
| **C-03** | **凭证明文零泄露** | `base_url + api_key` 明文只允许存在于：凭证上下文的内存、检测探测路径的请求头。任何日志、异常栈、指标、审计 payload、前端响应、错误消息都不得含明文。 |
| **C-04** | **契约单一真源** | 端点、OpenAPI、JSON Schema 全部由 `tools/gen-backend-models.py` 生成。**改端点必须先改生成器再重生成**。手写契约只能作为规格意图，不得作为实现真源。 |
| **C-05** | **状态流转必须经领域方法** | 禁止在 Service/Controller 里直接赋状态字段绕过状态机校验。非法流转统一拒绝 `E-1601`。 |
| **C-06** | **跨上下文不联表写** | 跨限界上下文查询走只读视图；写操作只能在本上下文聚合内。 |
| **C-07** | **审计不可变** | `aap_audit_log` 仅 INSERT/SELECT；敏感操作（凭证查看、定价写入、批量启停、人工放行）必须留痕含 before/after。 |

## 3. 技术栈与工程约束

- **语言/框架**：Java 25；Spring Boot 由 BOM 管理（`4.1.1`，项目 POM 不得自指定版本）；
  `import com.hioas.framework:hioas-dependencies:1.0.0-SNAPSHOT`（type=pom, scope=import）。
- **持久化**：PostgreSQL；MyBatis-Flex；迁移用 Flyway（顺序版本号，禁止修改已应用脚本）。
- **前端**：管理端 Vue 3 + Element Plus + Vite；供应商端 uni-app。
- **金额**：`numeric(18,6)`/`numeric(20,8)`，单位 USD 或 USD/1M tokens；**禁止浮点**。
- **时间**：`timestamptz` UTC 存储；周期口径统一**自然月 UTC**（与用量窗口同口径，不得引入第二套时间定义）。
- **测试门禁**：全量 `mvn test` 必须零失败；冻结端点清单断言（`EndpointCoverageTest`）随端点变更同步更新。

## 4. 交付与证据纪律

| # | 规则 |
| --- | --- |
| **D-01** | 所有结论必须给出可核验证据：源码「文件:行号」、命令输出、或官方文档 URL。禁止凭命名推测。 |
| **D-02** | 红基线必须先取得（TDD）：先让契约测试红在「能力缺失」，再实现转绿。红基线证据落盘。 |
| **D-03** | 跑批证据文件**不得用固定名 + `tee`** —— 多轮跑批会静默覆盖，只留末次。中间态加阶段后缀。 |
| **D-04** | 门禁口径与实现必须同步：新增能力要**同时**收紧判据（含反向断言：确认旧文案/旧占位已消失）。 |
| **D-05** | 前端**不得显示假成功**：后端未提供的端点不得假装触发；不得展示「系统不生成 X」这类与实现矛盾的过时文案。 |
| **D-06** | 提交卫生：本仓库多会话共用，**禁止 `git add -A`**；逐路径显式添加，他方在制品只登记、不碰、不 revert。 |
| **D-07** | 未验证不得声称完成：编译通过 ≠ 链路打通；报「通过」必须附当次真实运行输出。 |

## 5. 未决项纪律

未知即未知：待实测/待拍板的事项必须显式记为 `[NEEDS CLARIFICATION]` 或列入 research 的「待实测项」，
**不得**以「应该可以」「理论上没问题」代替实测结论；也不得因为某项未定而虚构一个默认行为。

---

## 6. 架构不变量

1. 全平台只有 `sync` 上下文允许调用 new-api（防腐层 ACL 是唯一出口）。
2. 所有外部 HTTP 出站走统一出站网关（SSRF 防护 + 超时 + 重试 + 脱敏）。
3. 核心域（检测验证、计费编译、渠道治理）不得直接依赖 new-api 客户端，须经端口接口注入。
4. 幂等：外部写操作必须有幂等键；重试不得产生重复副作用。
5. 写外部系统遵循「读前对比 → 写入 → 写后回读」，不一致必须告警而非静默成功。
